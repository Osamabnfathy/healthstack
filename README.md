# Medicare 🏥

A complete healthcare mobile application developed using **Flutter** for Android, with a clean and user-friendly design. The app allows **patients** to manage their personal health-related needs and interact with hospitals and doctors seamlessly.

---

## 🌟 Features

* ✏️ Edit personal profile data
* 🔒 Change password securely
* 💼 Book appointments with doctors from any registered hospital
* 📝 View all registered hospitals
* 🧑‍⚕️ View all doctors from any registered hospital
* ⏰ View booked appointments:

  * Upcoming
  * Completed
  * Cancelled
* 📄 View prescriptions
* 📈 View medical reports

## 🏃 Getting Started

* Clone the repo

```bash
git clone https://github.com/Osamabnfathy/healthstack.git
```

* Navigate to the project directory

```bash
cd healthstack
```

* Install dependencies

```bash
flutter pub get
```

* Run the app

```bash
flutter run
```

## 📊 Tech Stack

* Flutter & Dart
* RESTful APIs
* Dio for requests
* BLoC for state management
